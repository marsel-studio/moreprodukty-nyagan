# Сайт «Морепродукты Нягань»

Витрина с корзиной, заказ с сайта, админка и уведомления в Telegram.
Внешних библиотек нет: нужен только **Node.js 18 или новее**. Установка пакетов не требуется.

## Запуск за минуту

```bash
node server.js
```

В консоли появится **пароль администратора** (показывается один раз). Сайт: `http://localhost:3000`, админка: `http://localhost:3000/admin/`.
Забыли пароль: `node server.js --reset-password` (выдаст новый). Свой пароль при первом запуске: `ADMIN_PASSWORD=мойпароль node server.js`.

Каталог из 48 позиций уже загружен из прайса ВК. Всё правится в админке.

## Что умеет админка (`/admin/`)

| Раздел | Что можно |
|---|---|
| Заказы | Видеть заказы, менять статус, звонить клиенту одним нажатием, отправить в Telegram повторно |
| Каталог | Добавлять и править позиции: название, описание, цена, старая цена, фасовка, фото, значок, отметки («Хит», «Новинка»…), наличие, порядок |
| Категории | Добавлять, переименовывать, менять значок и цвет |
| Вид сайта | Заголовок, тексты всех блоков, главное фото, цветовые схемы, свои цвета, шрифты, вид карточек, логотип, бегущая строка, включение и выключение блоков. Справа живой предпросмотр |
| Контакты и доставка | Телефон, ВК, Telegram, WhatsApp, адрес, график, условия доставки, минимальная сумма |
| Telegram | Пошаговое подключение бота, поиск chat_id, тестовое сообщение |
| Аккаунт | Смена пароля, резервная копия |

## Telegram

1. В Telegram откройте `@BotFather`, отправьте `/newbot`, получите токен.
2. Напишите своему боту любое сообщение.
3. В админке: Telegram → вставьте токен → «Найти мой чат» → «Отправить тест» → «Сохранить».

Заказ сохраняется на сервере в любом случае. Если Telegram недоступен, сайт повторит отправку сам (в течение суток), а в админке есть кнопка «Отправить в Telegram снова».

## Выкладка в интернет

Подойдёт любой VPS или хостинг с Node.js. Обычный хостинг «только PHP» не подойдёт.

**VPS (Ubuntu), коротко:**
1. Загрузите папку на сервер, например в `/opt/moreprodukty`.
2. Создайте `/etc/systemd/system/moreprodukty.service`:
   ```ini
   [Service]
   WorkingDirectory=/opt/moreprodukty
   ExecStart=/usr/bin/node server.js
   Environment=PORT=3000 TRUST_PROXY=1
   Restart=always
   User=www-data
   [Install]
   WantedBy=multi-user.target
   ```
   Затем `systemctl enable --now moreprodukty` и `journalctl -u moreprodukty` (там пароль админа).
3. Поставьте nginx с HTTPS (Let's Encrypt) и проксируйте на `127.0.0.1:3000`, передавая `X-Forwarded-For` и `X-Forwarded-Proto`.
4. В админке (Вид сайта → Для поисковиков) укажите адрес сайта.

**Docker:** `docker build -t moreprodukty . && docker run -d -p 3000:3000 -v moreprodukty-data:/data moreprodukty`

Переменные: `PORT`, `HOST`, `DATA_DIR` (где хранятся данные), `ADMIN_PASSWORD`, `TRUST_PROXY=1` (за nginx).

## Данные и резервные копии

Всё хранится в папке `data/` (каталог, настройки, заказы, загруженные фото, пароль). Копируйте её целиком. В архив для выкладки она не входит.

## Что заменить перед запуском

- **Главное фото.** Сейчас стоит временное стоковое фото из архива. Замените своим: Вид сайта → Главное фото. Проверьте права на фото ВК, прежде чем публиковать.
- **Фото товаров.** У позиций без фото показывается нарисованный значок. Свои фото загружаются в карточке позиции, размер сжимается автоматически.
- **Цены и наличие.** Взяты из публикации ВК от 19 ноября. Перед запуском сверьте с реальным прайсом. Дату «Цены на …» меняет админка.
- **Контакты.** Заполнены телефон и ВК. Адрес, график, Telegram и WhatsApp добавьте в «Контакты и доставка»; пустые поля на сайте не показываются.
